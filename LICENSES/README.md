Recordings were trimmed, faded, level-matched and encoded to MP3; each file is named by its measured root note as a MIDI note number. The kick and the clap's reverb layer were designed for this project. Vocal samples keep the SoundFont's loop points, with tuning corrections applied to their root notes.
